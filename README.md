# Key Features and Functionality
###	Home – the first page the user is welcomed to the website with designs to make them want to go onto the other pages and read through.
### About us- this contains the organisations history, vision and mission including the goals and objectives of the organisation. Gives the user insight on who we are, what we stand for and where we want to go
### Contact- contains the information on communication options that can be used like the company email address, phone numbers of offices in every province and the physical address of these offices. This allows the user to directly speak to the organisation and ask more in depth questions and get clarity on any information they feel they may not fully understand.
### Rentals- this section has all the apartments and townhouses available for renting including the price, location and updated picture of the property. The client can look through the multiple options and see the agent allocated to that specific area. The top part has a search bar where you can filter the property from the bedroom number to the prices and the areas.
### Houses- has all the houses for sale. The user can scroll through all the pictures with included prices, details of agent to speak to and area. It also has the filter search where the user does not have to scroll through many pages of houses in other provinces or beyond their budget.
